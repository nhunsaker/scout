New: when a scan [attributes code owners](https://scoutui.dev/docs/guides/attribute-code-owners), a component's **Usage** tab shows who still uses it. The file list gets an **Owner** column, an **Owner** filter above it lets you keep uses by one or more owners (or **No owner**), and a **By owner** summary lists uses per owner so a design-system team can see which teams still use a component.

A tag can now select components by **name** or by a **scanned property**, not only by package. In the tag form, **Component names** matches a component's display name the same way **Packages** matches a package name, and **Property** matches one of a [hook script](https://scoutui.dev/docs/guides/add-custom-properties)'s keys, by **Equals** or **Contains**. A component matches a tag when it matches any part of the tag's rule — a stored package-only tag behaves exactly as it always has. See [Tags](https://scoutui.dev/docs/guides/dashboard/tag-your-libraries).
